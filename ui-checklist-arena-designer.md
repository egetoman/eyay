## Arena Designer UI Manual Test Checklist

- Open Arena Designer and confirm layout loads without errors.
- Left click on player side to add tower; right click removes it.
- Bridge placement snaps across the river at valid positions.
- Placement mode, tower owner, and tower type dropdowns affect placement the same way.
- Save Layout persists and Active Layout reloads with identical data.
- Reset to Active Layout restores original active layout.
